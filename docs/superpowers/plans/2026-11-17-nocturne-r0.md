# Nocturne R0 Foundation Implementation Plan

**Goal:** Establish reusable Nocturne tokens and low-level UI primitives for later page migrations while preserving current screens.

**Authority:** Approved R0 brief supplied 2026-11-17; ADR-001 and ADR-002 govern the React and custom CSS architecture.

**Architecture:** Add a distinct `--noc-*` token layer and opt-in `noc-*` component styles. Keep the new primitives outside the current application tree until a later redesign task adopts them. Native controls handle simple interactions; existing Radix tabs remain the tabs foundation.

**Constraints:** Work in the main worktree; preserve unrelated edits; do not alter page, shell, poker, card, parser, or tournament behavior; do not add dependencies, commit, or deploy. The guideline names grades without hex values, so sample the flat grade bar in the approved dashboard screenshot. Exact font assets are not available locally; define safe font stacks.
